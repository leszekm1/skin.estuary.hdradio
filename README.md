# Estuary HD Radio

Kodi Omega Estuary skin variant that displays metadata, cached artwork, and
station logos published by `service.hdradio.nowplaying`.

## Releases

Download the installable ZIP from the GitHub Releases page and install it with
Kodi's **Add-ons > Install from zip file** command. Install and enable the
sidecar service first. Tagged versions are packaged, validated, checksummed,
and published by GitHub Actions.
